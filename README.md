# Студенческая лента УУНиТ

Прототип информационного сервиса для ведения, наполнения и модерации новостной ленты студенческих мероприятий Уфимского университета науки и технологий (УУНиТ).

Проект представляет собой клиентское веб-приложение, разработанное в рамках хакатона. Сервис полностью автономен: он не требует развертывания серверной части или базы данных, так как для хранения данных используется `localStorage` браузера. Это позволяет запускать проект на любом статическом хостинге (например, GitHub Pages) и демонстрировать его работу на любом устройстве.

## ✨ Основной функционал

### Для студентов:
*   **Регистрация и авторизация** в системе.
*   **Создание записей**: форма отправки новости с заголовком, текстом и ссылкой на изображение.
*   **Взаимодействие с лентой**: постановка лайков и написание комментариев к новостям.
*   **Личный кабинет (Профиль)**:
    *   Просмотр личных данных и накопленных баллов (начисляются модератором за одобренные новости).
    *   Просмотр списка всех своих записей с отображением их текущего статуса (Опубликовано, На модерации, Требует правок).
    *   Редактирование записей (после редактирования запись снова отправляется на проверку модератору).
    *   Просмотр комментариев модератора (причины отклонения или возврата на доработку).

### Для администраторов (модераторов):
*   **Панель модерации**: отдельная страница со списком записей, ожидающих проверки.
*   **Одобрение**: публикация новости в общей ленте с автоматическим начислением баллов автору (+5 баллов).
*   **Возврат на доработку**: возможность отклонить запись с обязательным указанием причины (текст причины отображается в профиле автора).
*   **Прямая публикация**: кнопка «Предложить новость» на главной странице для админа работает как «Опубликовать» (запись публикуется сразу, минуя модерацию).

### Общие функции интерфейса:
*   **Просмотр новости**: открывается в модальном окне поверх ленты без перезагрузки страницы, что обеспечивает плавный пользовательский опыт.
*   **Смена темы**: переключатель светлой и темной темы (выбор сохраняется в браузере пользователя).
*   **Всплывающие уведомления**: все системные сообщения (успешная отправка, ошибки, результаты модерации) выводятся в виде красивых тостов в правом верхнем углу.
*   **Адаптивность**: корректное отображение на мобильных устройствах, планшетах и ПК.

## 🛠 Технологический стек
*   **Frontend**: HTML5, CSS3, JavaScript (ES6+). Без использования сторонних фреймворков и сборщиков для максимальной простоты деплоя.
*   **Хранение данных**: Web Storage API (`localStorage`).
*   **Дизайн**: Фирменный стиль УУНиТ (цветовая палитра: фиолетовый, оранжевый, темно-синий; строгие шрифты без засечек).
*   **Архитектура**: Разделение логики на модули (модульный JS, вынесенные CSS-стили, переиспользуемые компоненты).
